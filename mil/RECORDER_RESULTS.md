# Within-recorder results

Generated by `mil/recorder_report.py`. Development data only; the sealed groups were never loaded.

**Why this test:** every earlier model flags healthy folders 8 and 24, which share recorders with infested trees. Within one recorder the device is the same, so only a difference in the trees can separate healthy from infested. Three recorders recorded both classes:

| Recorder | Healthy folder | Infested folders |
| --- | --- | --- |
| 2538 | 24 | 1, 3, 5, 11, 13, 16, 18, 20, 22, 26, 34 |
| 7260 | 8 | 2, 4, 6 |
| 8391 | 25 | 12, 14, 17, 19, 21, 23, 27 |

**R-\* runs:** tree-safe leave-one-recorder-out (6 folds, one per development recorder). The test recorder is never heard in training, and a tree group with any folder on it is removed from training.
Within-recorder AUC is tree-weighted within each recorder; 0.5 is chance. Spread is over seeds.
