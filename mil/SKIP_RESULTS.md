# Skip-window campaign: per-window results (unweighted)

Generated by `mil/skip_report.py`. Every window (one bag of K recordings fed to the model) counts once; threshold 0.5; 95% intervals are tree-cluster bootstraps (1,000 draws). Held-out folds of tree-grouped 10-fold CV on development data only; the sealed groups were never loaded.

**XS-\* runs:** skip-window training (K recordings in time order from a random stretch of at most 48 h), 10x the training windows of every earlier run (115,200 bags per fold vs 11,520), tree-grouped 10-fold CV, seed 42. More windows reuse the same recordings and the same 21 trees (5 healthy); they are not new data. S-skip / B0 rows are the earlier 11,520-bag runs for reference (B0 has no skip windows).

**Architectures:** log-mel CNN = trainable 4-block CNN clip encoder on log-mel 64x626; MFCC 13xT CNN = trainable 4-conv CNN clip encoder on whole-clip MFCC (13 coefficients x T time chunks of the 20 s clip, mean-pooled); frozen AST / BEATs / PANNs = frozen AudioSet-pretrained embeddings (768 / 768 / 2048-d). Every model then uses gated-attention MIL pooling and a linear classifier. No pretrained MFCC encoder was used (none suitable exists; see the campaign notes in AGENTS.md).
